# Решение

Повторно использовать полный захват html-to-image и существующий finally восстановления интерфейса. PDF содержит пропорционально уменьшенный снимок на одном альбомном A4 с полями; большие планы требуют увеличения при просмотре. XLSX содержит снимок текущего вида, таблицу всех задач (включая скрытых потомков) и связей. Дата окончания включительная, даты — ячейки Excel, пользовательский текст не исполняется как формула.

Браузер не предоставляет записи PDF/XLSX напрямую. Загружать по требованию точные версии pdf-lib 1.17.1 и ExcelJS 4.4.0 из jsDelivr. Сбой загрузки допускает повтор. Файлы формируются локально, данные плана на сервер не отправляются. Сохраняется ограничение canvas по размеру.

API: [pdf-lib](https://pdf-lib.js.org/docs/api/classes/pdfdocument), [ExcelJS](https://github.com/exceljs/exceljs/tree/v4.4.0).
