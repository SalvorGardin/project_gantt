# Поле названия и помощь по связям

Поле названия не растягивается внутри строки с эмодзи. Оно должно занимать всю доступную ширину формы рядом с кнопкой эмодзи во всех режимах общего редактора. Кнопка «Связи» должна открывать центральное модальное окно с инструкцией вместо нижней полосы. Пассивная подсказка после загрузки остаётся ненавязчивой.
