## ADDED Requirements

### Requirement: Расположение действий проекта
Приложение SHALL показывать кнопки создания группы, задачи и вехи справа в строке состояния под хедером; хедер SHALL не содержать кнопку «Загрузить» и кнопки создания элементов.

#### Scenario: Работа с планом
- **WHEN** пользователь открывает проект
- **THEN** количество элементов и состояние находятся слева, кнопки создания справа, а нажатия открывают прежние формы соответствующего типа.

#### Scenario: Недостаточная ширина
- **WHEN** содержимое строки не помещается по ширине
- **THEN** строка увеличивает высоту и переносит содержимое без наложения кнопок на статус.
