# Выбор эмодзи клавиатурой — 22 октября 2026

Кликабельные span заменены нативными button type=button. Сохранены обработчик click, размеры и внешний вид; добавлен видимый focus-visible. После выбора фокус возвращается на кнопку открытия списка. Собственные обработчики клавиш и зависимости не добавлены.

`node tests/emoji-browser.cjs [URL]` прошёл в Chromium через file://: открытие списка Enter, переход Tab через поле названия к кнопкам, выбор Enter и Space, закрытие списка, возврат фокуса, сохранение формы и повторное открытие с выбранным значком. Ошибок страницы нет. Существующие Playwright/Chromium доступны через NODE_PATH/BROWSER_EXECUTABLE.

Отрицательная проверка: при подстановке span вместо button только в тестовом браузере тот же окончательный сценарий падает на проверке фокуса после Tab. Рабочий код для этой проверки не менялся.

Синтаксис app.js, git diff --check, структура требований и локальные ссылки OpenSpec проверены. CLI OpenSpec недоступен, его валидация не выполнялась. Скринридер, другие браузеры, полный цикл управления фокусом диалогов и названия цветовых кнопок в этот этап не входили.
