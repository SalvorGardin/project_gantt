## ADDED Requirements

### Requirement: Порядок импортируемых элементов
Приложение SHALL упорядочивать корневые элементы и детей каждого родителя по возрастанию sort_order, сохраняя порядок массива при равных значениях; отсутствующее значение считается нулём.

#### Scenario: Перемешанный массив
- **WHEN** элементы JSON перечислены не по sort_order, в том числе дети раньше родителей
- **THEN** дерево отображает правильную иерархию и порядок внутри каждой ветки; повторное сохранение и открытие сохраняет этот порядок и даты.

#### Scenario: Равные и отсутствующие значения
- **WHEN** sort_order одинаковый или отсутствует
- **THEN** элементы с одинаковым нормализованным значением сохраняют взаимный порядок массива.
