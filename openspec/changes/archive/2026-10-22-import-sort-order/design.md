## Decision
Стабильно сортировать копию массива в specToGantt по числовому sort_order. Глобальная сортировка перед parse обеспечивает тот же порядок внутри каждого родителя; DHTMLX строит дерево по parent_id. Исходный массив не менять. Отсутствующий sort_order трактуется как 0 согласно действующему валидатору: перед положительными значениями. При равенстве, в том числе без sort_order, сохраняется порядок массива. Экспорт по-прежнему записывает последовательные номера внутри каждой ветки.

## Verification
Импорт перемешанных корней и детей до родителей, вложенные задачи, равные/отсутствующие значения, оба пути импорта, save/load без изменения дерева и дат.
