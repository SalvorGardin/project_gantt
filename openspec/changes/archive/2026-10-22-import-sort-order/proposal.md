## Why
Импорт копирует sort_order, но не использует его для порядка строк. Внешние JSON с перемешанным массивом отображаются неверно.

## What Changes
Сортировать подготовленные элементы по sort_order перед передачей диаграмме. Стабильная сортировка сохраняет исходный порядок при равных значениях. Отсутствующее значение уже нормализуется валидатором в 0.

## Capabilities
### Modified Capabilities
- project-files: порядок элементов при импорте.

## Impact
Минимальное изменение specToGantt, расширение существующей браузерной проверки. Формат JSON v1 и валидатор не меняются.
