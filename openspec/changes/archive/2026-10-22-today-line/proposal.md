# Линия сегодняшнего дня

Существующий код запрашивал marker plugin, но в подключённом файле dhtmlx-gantt 10.0.3 API addMarker отсутствует, и защитная проверка пропускала создание. Добавить одну DOM-линию внутри штатной прокручиваемой области задач, используя posFromDate и событие рендера. Привязать к началу локального дня, показать подпись «Сегодня», не перехватывать мышь. Не расширять календарь за сроки проекта ради маркера. Новых зависимостей нет.
