## ADDED Requirements

### Requirement: Описание сервиса на стартовом экране
Стартовый экран SHALL описывать GanttFlow как бесплатный сервис диаграмм Ганта, перечислять задачи, группы, вехи, зависимости, сроки, прогресс и форматы экспорта; SHALL объяснять ручное сохранение в JSON на компьютер и повторную загрузку файла.

#### Scenario: Знакомство с сервисом
- **WHEN** посетитель открывает приложение без проекта
- **THEN** видит описание и действия создания, загрузки и демо; при недостаточной высоте окна содержимое доступно прокруткой.
