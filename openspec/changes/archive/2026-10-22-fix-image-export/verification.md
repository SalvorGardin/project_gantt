# Проверка экспорта PNG/JPEG

22 октября 2026. Реализация остаётся в app.js, новые зависимости не добавлены.

## Выполнено

- tests/export-browser.cjs: настоящий DHTMLX и html-to-image 1.11.11 в Chromium, прямое открытие index.html через file://.
- PNG и JPEG в светлой/тёмной теме: файлы корректно декодируются, размер 3128×1332 при окне 1200×700. В нижнем правом участке обнаружены пиксели последней задачи (PNG >7200, JPEG >6300); значит захват охватывает конец шкалы и нижние строки.
- Визуально просмотрены светлый PNG и тёмный JPEG: вся шкала и последняя строка присутствуют. Контрольные изображения сохраняются тестом в /tmp/gantt-export-check (временные, не часть репозитория).
- До/после сравниваются inline-размеры контейнера, фактическая высота, настройки ширины таблицы, прокрутка, видимость панелей, сериализованный план и dirty. Свёрнутая группа остаётся свёрнутой.
- Имя из несохранённого переименования «Новый план /:*?» даёт «Новый план_<локальная дата>.png/jpeg»; полностью недопустимое имя даёт gantt. Параллельный запуск проигнорирован, повторный после ошибки работает.
- Семь отказов: чтение состояния, изменение размеров, захват, исключение кодирования, null Blob, создание object URL, запуск скачивания. После каждого интерфейс восстановлен, индикатор закрыт, следующий запуск доступен.
- Пустой новый проект экспортируется без зависания; dirty остаётся установленным.
- 50 тестов проверки файлов/сессии прошли; синтаксис app.js и локальная структура/ссылки OpenSpec проверены.

## Границы

CLI OpenSpec отсутствует в PATH: CLI validate не выполнялся, синхронизация спецификаций и архивирование выполнены вручную. Другие браузеры, HTTP именно для нового экспортера и очень большие canvas в этом этапе не проверялись. Максимальный размер зависит от браузера/памяти; библиотека может уменьшать слишком большое изображение. Запуск скачивания не подтверждает запись файла на диск.
