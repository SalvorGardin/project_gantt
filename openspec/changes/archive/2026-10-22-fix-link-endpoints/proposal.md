# Исправление создания связей

Перетаскивание должно сохранять выбранные концы FS/SS/FF/SF. Числовой 0 и принудительное FS мешают штатной обработке DHTMLX. При создании и смене типа связи принимающая задача сдвигается к выбранной дате источника с сохранением длительности. Окончание означает включительную дату таблицы; для вехи — её дату. Импорт не пересчитывает сроки. Постоянное каскадное планирование при последующих правках задач не входит в изменение.
