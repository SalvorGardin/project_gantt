## Decisions

- Выделить чистую prepare-функцию в js/project-file.js, доступную обычному script и Node-тесту. Сохранить file:// и HTTP, не вводить ES modules.
- Даты v1 не сдвигать. Для задач конец позже начала (исключительная граница); веха допускает отсутствующий конец с нормализацией к началу. Отсутствующие необязательные поля получают прежние значения по умолчанию.
- Проверять графы итеративно, чтобы повреждённая глубокая иерархия не переполняла стек валидатора. ID нормализовать в строки, запретить корневой 0 и опасные ключи объектов библиотеки.
- Снимок диаграммы перед заменой сохранять через serialize с копированием; при parse/render-ошибке восстановить его. На время загрузки не запускать прикладные изменения связей/dirty/родителей. При невозможности отката предложить скачивание снимка для восстановления.
- Оба input используют один асинхронный обработчик чтения, устаревший результат чтения не применяется. Подтверждение замены проверяет актуальный dirty, а не состояние на момент выбора файла.
- Не очищать текущий проект при открытии формы нового. Только подтверждённое создание меняет данные. Ошибку не скрывать за сообщением об успехе.
- Проверять выходной JSON до запуска скачивания. Сохранять исходные названия, генерировать sort_order по текущему обходу дерева. Не угадывать иной порядок старых входных массивов.

## Verification

Node assert-тесты для валидатора и управления сессией с подставным DOM/Gantt; по возможности браузерные проверки на настоящем DHTMLX. Поведение экспортированных изображений в этот этап не входит.
