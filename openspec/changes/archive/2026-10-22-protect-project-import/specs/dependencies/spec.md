## MODIFIED Requirements

### Requirement: Циклы связей со строковыми ID
Приложение SHALL приводить допустимые идентификаторы к единому строковому представлению и отклонять любую новую связь, замыкающую цикл, включая связь элемента с самим собой.

#### Scenario: Числовые идентификаторы
- **GIVEN** загружены допустимые числовые идентификаторы элементов 1 и 2 и связь 1 → 2
- **WHEN** пользователь создаёт 2 → 1
- **THEN** связь отклоняется с сообщением о цикле.

#### Scenario: Строковые идентификаторы
- **GIVEN** существует A → B
- **WHEN** пользователь создаёт B → A
- **THEN** связь отклоняется с сообщением о цикле.

## ADDED Requirements

### Requirement: Сохранение импортированных типов
Приложение SHALL сохранять типы FS, SS, FF и SF при загрузке проекта без принудительной замены на FS.

#### Scenario: Повторный импорт
- **WHEN** пользователь сохраняет и повторно загружает план со связью SS
- **THEN** тип этой связи остаётся SS.
