## Decision
Переиспользовать текущие div-диалоги и closeModal. Один небольшой стек открытых окон хранит инициатор; Tab и focusin удерживают фокус в верхнем окне, Escape закрывает только его. Нативные кнопки сохраняют Enter/Space. Переход на dialog потребовал бы менять слои всех оверлеев и уведомлений; для существующего интерфейса достаточно общего управления фокусом. Фокус задаётся синхронно, без таймеров. Если инициатор удалён/скрыт, возврат в нижнее окно либо область диаграммы.

«Нет новых изменений» вместо «Сохранено» описывает отсутствие изменений после загрузки/последнего запуска скачивания, не наличие файла на диске. После формы — «Изменения применены к плану»; после скачивания JSON — предложение проверить файл в загрузках. Dirty сбрасывается по существующему контракту запуска скачивания.
