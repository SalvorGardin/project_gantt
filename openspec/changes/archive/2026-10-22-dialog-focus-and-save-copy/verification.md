# Диалоги и сообщения сохранения — 22 октября 2026

Добавлено общее openModal/closeModal со стеком инициаторов. Начальный фокус синхронный, Tab/Shift+Tab циклические внутри верхнего окна; focusin возвращает фокус из фона. При закрытии фокус возвращается видимому доступному инициатору, иначе нижнему диалогу или диаграмме. Escape сначала закрывает список эмодзи, затем верхний диалог; вложенное подтверждение не уничтожает нижнюю форму. Поля скрытых секций и отключённые элементы не входят в цикл.

«Сохранено» заменено на «Нет новых изменений» с пояснением в title. Форма сообщает «Изменения применены к плану», JSON — «Скачивание JSON начато. Проверьте файл в загрузках браузера». Ошибка сообщает о неудачном запуске скачивания. Dirty и JSON v1 работают по прежнему контракту; подтверждение фактической записи файла не заявляется.
