# Favicon GanttFlow

## Why
У вкладки сайта нет собственной иконки.

## What Changes
Переиспользовать существующий SVG-логотип приложения в favicon.svg с фиксированными цветами и подключить через rel=icon. Опубликовать favicon.svg и обновлённый index.html, сохранив предыдущую версию вне публичного каталога.

## Impact
Без зависимостей, изменения JavaScript и конфигурации Caddy. Публичный каталог получает шестой файл. Для записи root-owned файлов требуется sudo.
