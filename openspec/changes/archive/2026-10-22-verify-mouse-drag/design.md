## Decision
Проверять через Playwright mouse.move/down/up, без вызова moveTask/updateTask/callEvent и без записи дат или parent в тесте. DOM используется для координат, Gantt — только для чтения результата, просмотра шкалы и регистрации событий. JSON загружается через интерфейс. Сохраняется существующая реализация: ошибки пересчёта родителей на этих сценариях не воспроизведены, менять app.js не требуется.

## Scope
Chromium, мышь, дневной масштаб, раскрытые ветки, Europe/Moscow. Touch, остальные браузеры и автоматическая прокрутка при drag за пределами окна не проверены.
