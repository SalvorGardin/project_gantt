# Реальное перетаскивание мышью — 22 октября 2026

`node tests/mouse-browser.cjs [URL]` прошёл в Chromium через file://, 1600×1000, Europe/Moscow. Для запуска используются существующие Playwright и Chromium через NODE_PATH и BROWSER_EXECUTABLE; зависимости приложения не менялись.

Проверены движения мыши с удержанием и отпусканием кнопки:
- Сдвиг задачи b на два дня: 12–16 октября → 14–18 октября (исключительный конец); оба уровня родителей расширяются до 5–18 октября.
- Правый край b сдвинут назад на два дня: конец становится 16 октября, родители сужаются до 5–16 октября.
- Строка b перенесена на вложенного родителя другой группы: старая ветка становится 5–9 октября, новая — 6–16 октября.
- Левый край c сдвинут на день раньше: начало c и принимающей ветки становится 5 октября.
- Последний ребёнок a перенесён из старой ветки непосредственно в другую группу: опустевший родитель сохраняет прежний диапазон.
- b возвращена в исходную ветку: оба уровня старой и новой веток пересчитаны; проверены parent, даты и duration.

Зафиксированы три onAfterTaskDrag и три onRowDragEnd от реальных действий мыши. Для переноса наблюдался порядок onRowDragStart → onBeforeTaskMove → onAfterTaskMove → onRowDragEnd. Тест не вызывает эти события вручную. Признак несохранённых изменений установлен. JSON v1 скачан и повторно загружен: дерево, даты и длительности совпадают. Ошибок страницы нет.

Ошибки пересчёта родителей не воспроизведены. app.js не менялся в этом этапе. Добавлена регрессионная проверка, уточнены спецификации. Проверки синтаксиса теста, git diff --check и локальных ссылок/структуры OpenSpec прошли. CLI OpenSpec отсутствует; его валидация не выполнялась.

Отдельное наблюдение: при сдвиге крайней задачи за исходную правую границу шкалы полоса может обрезаться (fit_tasks=false). Это ограничение отображения, не ошибка дат родителей; в регрессионном сценарии добавлена поздняя независимая задача, чтобы края полос оставались доступными. Изменение автоматического диапазона шкалы в этот этап не входило. Touch, другие браузеры и drag с автоматической прокруткой не проверены.
