## Why
Предыдущая проверка использовала API и вызовы событий, поэтому не подтверждает порядок событий настоящего перетаскивания мышью.

## What Changes
Добавить воспроизводимый браузерный сценарий с движениями мыши для сдвига и растягивания полос и переноса строк между группами. Исправить подтверждённые ошибки пересчёта родителей.

## Capabilities
### Modified Capabilities
- plan-editing: проверка сроков родителей после реального drag-and-drop.

## Impact
Браузерная проверка, app.js при обнаружении ошибки, документация OpenSpec. JSON v1 и зависимости приложения сохраняются.
